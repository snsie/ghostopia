# Ghostopia (working title)

A cute-spooky third-person voxel survival game about a small ghost who grows by scaring the living.
Godot 4.7.2; every asset is generated by Python scripts in Blender.

- Design: [docs/design/design-plan.md](docs/design/design-plan.md)

## Rebuild

Every asset is generated by code; run the stages in this order from the repo root (Git Bash).
`B="/c/Program Files/Blender Foundation/Blender 5.2/blender.exe"`

### Task 1: blocks, props, structures (about 2 minutes in total)

```bash
python blender/scripts/make_textures.py                     # shared prop textures -> assets/textures/
python blender/scripts/make_block_textures.py               # block atlas + normal/height/emission + blocks.json -> assets/blocks/
"$B" -b --factory-startup -P blender/scripts/preview_blocks.py        # renders/task1/blocks_{studio,night}.png
"$B" -b --factory-startup -P blender/scripts/build_props.py           # assets/props/*.gltf + props.json + blender/props.blend + renders/task1/props/
"$B" -b --factory-startup -P blender/scripts/build_structures.py      # assets/structures/*.json + blender/structures.blend + renders/task1/structures/
"$B" -b --factory-startup -P blender/scripts/style_check.py           # renders/task1/style_check_*.png + blender/style_check.blend
/c/Tools/Godot/godot_console.exe --headless --path . --import         # re-import into Godot
```

Options: `build_props.py -- --only candle,door_cottage`, `-- --cat hauntable`, `-- --no-render`;
`build_structures.py -- --only cottage_a,well`, `-- --no-render` (the JSON part also runs in plain
Python: `python blender/scripts/build_structures.py --json-only`).

Contact sheets (system Python + Pillow) are made with `tools/contact_sheet.py`, for example:

```bash
python tools/contact_sheet.py renders/task1/props_hauntable.png --cols 6 --cell 260 renders/task1/props/{door_cottage,candle,wardrobe}.png
```

### Task 2: characters (about 4 minutes in total, most of it preview rendering)

```bash
"$B" -b --factory-startup -P blender/scripts/build_characters.py      # assets/characters/*.gltf + characters.json + blender/characters.blend + renders/task2/
"$B" -b --factory-startup -P blender/scripts/char_lineup.py           # renders/task2/lineup_*.png + scale_check.json (imports the exported glTFs)
/c/Tools/Godot/godot_console.exe --headless --path . --import         # re-import into Godot
```

Options: `build_characters.py -- --only ghost,villager_farmer`, `-- --clips idle,walk` (re-render only these
strips), `-- --no-strips`, `-- --no-render`. The builder calls `python tools/char_sheets.py <names>` at the end,
which turns the per-frame previews in `renders/task2/frames/` (gitignored) into the committed sheets
`renders/task2/<name>_turnaround.png` and `renders/task2/<name>_anims.png`. Code: `lib_char.py` (skeleton,
lofts, skinning, face shape keys, FK/IK pose solver, NLA baking, export), `char_ghost.py` (player and worker
ghosts), `char_villagers.py` (villagers, items, control poses, foot-planted gait).

The committed sheets in `renders/task1/` are: `block_tiles`, `blocks_studio`, `blocks_night`,
`prop_textures`, `props_<category>`, `hauntables_normal_vs_haunted`, `structures_{day,night,interiors}`
and `style_check_*`. The per-item frames in `renders/task1/props/` and `renders/task1/structures/` are
gitignored and regenerated by the builders.

### Task 3: the island (about 2 minutes, most of it preview rendering)

```bash
"$B" -b --factory-startup -P blender/scripts/build_island.py          # assets/levels/millbrook_layout.json + millbrook_voxels.bin
                                                                      # + blender/millbrook_island.blend + renders/task3/*
python blender/scripts/build_island.py --json-only                    # layout + voxels only, plain Python, ~1 s
python tools/island_preview.py renders/task3/layout_markers.png --scale 6   # top-down debug map with areas and markers
```

Options: `-- --only millbrook,mill,plan`, `-- --moods night,day`, `-- --res 1920x1080`, `-- --no-render`,
`-- --no-plan`, `-- --no-blend`. The build calls `python tools/compare_sheets.py` at the end, which writes
`renders/task3/compare_<camera>_<mood>.jpg` (concept left, render right). Code: `lib_island.py` (the seeded
generator, pure numpy; the hand layout constants are at its top), `build_island.py` (output, Blender mesher,
moods, cameras). The generator is deterministic: Blender and plain Python write byte-identical files.

## Level data: `assets/levels/millbrook_layout.json`

Godot axes everywhere (x east, y up, z south), metres, 1 block = 1 m; `yaw` = Godot `rotation.y` in degrees
(0 = facing +Z). World cell `(x, y, z)` fills `[x, x+1] × [y, y+1] × [z, z+1]`.

| Key | Contents |
|---|---|
| `world` | `size` [192, 48, 192], `chunk_size` 16, `seed`, `origin`, `void_level` (0: below is the void), `surface_y`, `playable_y`, `palette` (block index → id, same as `blocks.json`), `block_counts`, `island` (centre, radius, floating cubes) |
| `world.voxels` | `res://assets/levels/millbrook_voxels.bin`: gzip of one `u8` block index per cell, **x fastest, then z, then y** (`index = x + sx * (z + sz * y)`, the blueprint order). Read with `FileAccess.get_file_as_bytes(path).decompress_dynamic(-1, FileAccess.COMPRESSION_GZIP)` |
| `kill_y` | below the island; anything falling past it respawns |
| `spawn` | `player_start` position and yaw (outside the mausoleum door) |
| `structures` | every stamped blueprint: `id`, `blueprint`, `anchor` (world cell of the pivot), `pivot` (metres), `yaw` (multiple of 90), `resident`, `area`, `footprint` [x0, z0, x1, z1], `rooms` as world AABBs. The voxels already contain them; this is for AI and haunting |
| `instances` | every glTF prop to place: `id`, `prop`, `gltf`, `pos`, `yaw`, `owner` (structure id or a zone: `graveyard`, `square`, `village`, `fields`, `windmill`), `hauntable` (door, floorboard, candle, oil_lamp, rocking_chair, wardrobe, portrait, doll, scarecrow, bell; null otherwise), `tags`, `area` |
| `markers` | `kind`, `id`, `pos`, `yaw`, `owner`, `area` (+ `resident`, `source` blueprint marker, kind-specific fields). Kinds: `player_start`, `respawn`, `villager_home`, `bed`, `chair`, `hearth`, `work` (`job`), `wander`, `door`, `window`, `entry`, `hiding_spot`, `creak`, `ore_node` (`block`, `cell`, `face`), `grave_node`, `weed_node`, `shelter` (`radius`), `cave_entrance`, `storage`, `worker_spawn`, `climb`, `anim_hub`, `roof_ridge`, `crossing`. Ids follow `<kind>_<resident or place>[_<detail>]`, e.g. `bed_agnes`, `door_pip_front`, `hiding_spot_bridge_nw` |
| `areas` | `id`, `name` (HUD), `kind`, `rect` [x0, z0, x1, z1] metres, `priority` (highest wins where rects overlap), `remembrance` (starting value, tuning), `resident`, `interior` rooms |
| `water` | `[{id: "stream", block, running_water: true, cells: [[x, y, z, flow_x, flow_z, waterfall], ...]}]` |
| `lighting` | `presets` `night` `dusk` `dawn` `day` `fading`: `sun`/`moon` (elevation, azimuth, `direction` the light travels, colour, energy, shadows), `ambient`, `sky` (top, horizon, void, moon disc, stars), `fog` (colour, density, height fog), `emission` (windows/lanterns/flames on or off, `GLOW_*` energy), `lamps_energy`, `saturation`, `exposure`, `glow_bloom`; `cycle` keyframes (`t` in [0, 1), nominal `hour`, `preset`) and phase ranges |
| `map` | `world_rect` covered by the plan render `renders/task3/millbrook_plan.png` (12 px per metre, image x → +x, image y → +z) |
